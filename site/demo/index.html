WHAT THE COMMAND DOES

See the real output path.

  1. 01

    Copies the sample

    Five tiny Paper Courier scene notes go into a fresh system temporary folder.

  2. 02

    Renders five shots

    The bundled safe renderer writes one PNG preview, a contact sheet, and a receipt per shot.

  3. 03

    Checks the cache

    The command runs again. All five shots reuse the local cache before it prints the output folder.
