HOW IT WORKS

Make preview renders you can repeat.

  1. 01

    List your shots

    Put shot names, source paths, frame rate, colour space, and command parts in one JSON file.

  2. 02

    Review the command

    plan shows the exact command. Nothing runs until you approve the executable name and add --yes.

  3. 03

    Use the outputs

    Each shot gets frames, a contact sheet, and a JSON receipt. The receipt records output hashes, frame rate, and colour space. Repeating unchanged work reuses local cached frames.

INSTALL THE CLI

Start with your own shot file.

Install your renderer separately. Shot Runner does not include Blender, ffmpeg, or other renderers.

$ cargo install --git https://github.com/B-Divyesh/sf-animation-shot-runner.git --rev 224935b96570655b27fbf4e26d39dedaaad87cc8 --locked animation-shot-runner
$ shot-runner demo
$ shot-runner init shots.json
$ shot-runner plan shots.json
$ shot-runner run shots.json --allow-command blender --yes
