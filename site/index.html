FIRST RUN / THREE COMMANDS

No daemon. No account. No render farm.

Install your renderer separately and observe its license. Shot Runner itself does not require ffmpeg unless your chosen command does.

$ shot-runner init shots.json
$ shot-runner plan shots.json
$ shot-runner run shots.json \
    --allow-command blender --yes
