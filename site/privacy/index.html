Privacy

Local CLI files

The CLI reads the paths in your shot file. It writes frames, contact sheets, caches, and JSON output records on your computer.

Documentation site

The site keeps a short-lived navigation marker in this browser tab. It restores scroll position and focus when you use Back or Forward.

The sample page stores one separate browser marker named demo:animation-shot-runner:opened. Reset recreates that marker. Start for real removes every Shot Runner demo key. The service worker caches public, same-origin documentation files so opened pages can be available offline.

Contact

Open privacy questions in the project’s public issue tracker. Do not include media or private project paths in an issue.
